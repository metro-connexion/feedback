# Feedback
## Project objective
This project is a third-party service for the metro-connexion application and its website; more information is available at [metro-connexion.org](https://www.metro-connexion.org). The purpose of this web platform is to provide an interface that allows users to report issues encountered while using these services.

## How it works
A user can open an issue on the platform by describing the problem they encountered and selecting the type of issue (for example: incorrect description, wrong number of stations, malfunction of the application, etc.). The choices will be predefined and the list can be updated as the application evolves. Other platform users can like and comment on the issue, which will help the metro-connexion teams prioritize issues based on likes and comments.

## User authentication
Initially, users will be able to sign in using email and password, and later via common SSOs (Google, Apple). It has not yet been decided whether this authentication will be shared across the entire metro-connexion ecosystem.
